# TDP Submission: AI, ML, GenAI, and LangGraph

Welcome to the **Machine Learning & Generative AI** repository, designed for the Training Development Program (TDP).
This repository is a completely beginner-friendly, production-ready guide to understanding and implementing AI models.

## 🚀 Project Overview
This project covers 4 core modules:
1. **Machine Learning Foundations** (Supervised, Unsupervised, Evaluation)
2. **Deep Learning & Neural Networks** (CNN, RNN, Optimizers)
3. **Generative AI + LangChain + RAG** (Prompt Engineering, Vector DBs, PDF QA)
4. **LangGraph + Multi-AI Agents** (Workflows, Tools, Planners)

## 🛠 Tech Stack
- **Python 3.10+**
- **ML/DL:** scikit-learn, pandas, numpy, matplotlib, seaborn, TensorFlow, Keras
- **GenAI:** OpenAI APIs, LangChain, HuggingFace, ChromaDB, LangGraph
- **API:** FastAPI

## 📂 Folder Structure
- `docs/`: Comprehensive, beginner-friendly Markdown documentation and diagrams.
- `datasets/`: Sample datasets used in scripts.
- `machine-learning/`: ML scripts for classification, regression, clustering.
- `deep-learning/`: Neural networks, CNNs, and RNNs.
- `generative-ai/`: Prompt engineering, RAG, and LangChain agents.
- `langgraph/`: Multi-agent systems and workflows.
- `api/`: FastAPI endpoints.
- `mini-projects/`: 5 complete end-to-end beginner projects.
