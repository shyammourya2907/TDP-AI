# Day 1: Introduction to Generative AI

## What is Generative AI?
Generative AI refers to algorithms (such as ChatGPT) that can be used to create new content, including audio, code, images, text, simulations, and videos.

## Gen AI Models
- **GANs (Generative Adversarial Networks):** Two neural networks (a generator and a discriminator) compete against each other to create highly realistic data (mostly images).
- **VAEs (Variational Autoencoders):** Encodes input data into a compressed representation and decodes it to generate new data.
- **Transformers:** The architecture behind Large Language Models (LLMs) like GPT-4. Uses "Self-Attention" to understand the context of words in a sentence.

## Popular Tools
- **DALL-E:** OpenAI's image generation model.
- **ChatGPT:** OpenAI's conversational text model based on Transformers.
- **Bard (Gemini):** Google's conversational AI model.

## Use Cases
- **Art:** Generating images and music.
- **Content Creation:** Writing articles, code generation.
- **Healthcare:** Discovering new drugs by generating molecular structures.

## Benefits vs Limitations
- **Benefits:** Massive time savings, automation of creative tasks, personalized tutoring.
- **Limitations:** Hallucinations (making things up), biased outputs, high compute costs.

## CNN vs GANs
- **CNN (Convolutional Neural Network):** Used for *understanding* and *classifying* data (e.g., "Is this a picture of a cat?").
- **GAN (Generative Adversarial Network):** Used for *creating* data (e.g., "Generate a picture of a cat that doesn't exist").
